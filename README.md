# 🚕 Buzz — الكلام بقى بفلوس

Buzz تطبيق ويب (PWA) بيحوّل فكرة عدّاد التاكسي لعدّاد كلام: تسيب التليفون جنبك،
وكل ثانية حد بيتكلم فيها بتتحسب فلوس، ولما تقفله بيطلعلك فاتورة تبعتها لصاحبك.
تحت النكتة دي نظام ذكاء اصطناعي حقيقي شغّال بالكامل جوه المتصفح: كشف كلام عصبي
(Silero VAD) بيفرّق الكلام عن الضوضاء والتلفزيون، وتعرّف على صاحب الصوت
(WeSpeaker) يخليك تحاسب نفسك بس، وفصل متحدثين تلقائي يقسّم الفاتورة على كل
الحاضرين من غير ما حد يسجّل صوته. البصمة بتتعلّم مع الاستخدام، والتطبيق بيفتكر
نفس الأشخاص بين الجلسات، وكل جلسة بتتحفظ في تاريخ كامل. كل ده صفر سيرفر وصفر
بيانات بتطلع بره جهازك، وبواجهة عربي/إنجليزي كاملة.

Buzz is a web app (PWA) that turns the taxi-meter idea into a talking meter:
leave your phone nearby, and every second someone talks gets charged — end
the ride and it hands you a receipt to send them. Behind the joke is a real
AI pipeline running entirely in the browser: neural speech detection (Silero
VAD) that tells actual talking apart from noise and TV, speaker verification
(WeSpeaker) so it only bills your own voice, and automatic speaker
diarization that splits the bill across everyone in the room with no one
having to enroll. The voice print keeps learning as you use it, the app
remembers the same people across sessions, and every session is saved to a
full history. All of it runs with zero servers and zero data leaving your
device, in a fully bilingual Arabic/English interface.
